Agent Safety Check

Checks any AI skill, agent, custom GPT or Gem, MCP setup or system prompt for prompt-injection risk, and tells you exactly what to change. Use it before you install someone else’s skill, or while you build your own.

⬇ Download the skill .zip · 2 files or read SKILL.md · scan.py

What it looks for

1 · Private dataWhat can it read that you wouldn’t publish?
2 · Untrusted contentWhat text reaches it that someone else wrote?
3 · A way outHow could data leave, or harm be done?

All three together = high risk. It also finds instructions hidden in the skill itself (comments, invisible characters, encoded text), actions that run without your approval, and scripts that reach the network or your secrets. You get a verdict, the findings and the top three fixes.

Install

Claude Code

Unzip into your skills folder, then ask: “Check the skill in ./some-skill for prompt-injection risk.”

unzip agent-safety-check.zip -d ~/.claude/skills/

Claude app (claude.ai, desktop)

Settings → Capabilities → Skills → upload the .zip. Then attach or paste the skill / prompt you want checked.

ChatGPT or Gemini

Open SKILL.md, copy it into a new chat (or a custom GPT / Gem’s instructions), then paste or upload the skill, prompt or config to check.

Just the scanner

Python 3, no dependencies. Read-only: it never runs the files it scans.

python3 scan.py path/to/skill-folder

A review aid, not a guarantee. The fix is never “add ignore injections to the prompt” — it’s removing or gating one of the three legs. From the NomadCruise talk “Hacked by Your Own AI”, Nov 8 2026 · Tonight on Deck 7
